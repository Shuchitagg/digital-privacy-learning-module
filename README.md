# Digital Privacy & Safe Online Practices

## Project purpose
This is a self-contained interactive learning module created as a professional-learning and digital-platform support portfolio sample.

## Demonstrated skills
- Interactive learning design
- Multiple-choice knowledge checks
- Scenario-based learning
- Drag-and-drop categorization
- Immediate learner feedback
- Progress tracking and scoring
- Accessible, responsive interface design
- Clear user instructions and plain-language writing
- Privacy-conscious design: no learner information is transmitted or stored

## How to open
1. Download the project folder or ZIP file.
2. Open `index.html` in a modern web browser.
3. No installation or internet connection is required.

## Suggested portfolio description
**Digital Privacy & Safe Online Practices – Interactive Learning Module**

Designed and developed a self-paced professional-learning module featuring learner objectives, scenario-based instruction, interactive questions, drag-and-drop practice, automated scoring, progress tracking, reflection prompts, and accessible navigation. Built as a platform-neutral demonstration of digital-learning content development and virtual user support.
